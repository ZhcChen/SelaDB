# 改动前后成对比较

> 用 `node tests/review.mjs --compare` 生成。绝对打分有 ±1 分的抖动,
> 成对比较问的是「哪个更好」,相对判断稳定得多。

## 01-workbench-light —— 改后更好

改动后针对顶栏搜索框占位符（'搜索对象或执行命令'）、侧栏筛选输入框、各级标题与操作按钮等文字提高了对比度（掩码上可见全窗口的文本像素均有加深调整），彻底解决了改动前整体文本偏灰、可读性较弱的问题，信息读取更加清晰明了。

**新引入的问题**:无明显新问题，整体布局和间距保持一致，纯对比度优化。

## 02-grid —— 改后更好

差异掩码显示变动主要集中在界面所有中西文字体与图标渲染上（左上 Logo、搜索框占位符、侧边栏树节点文字及数据网格内的字符）。改动后文字笔画抗锯齿更加锐利扎实，解决了改动前中文字符轻微发虚发灰的问题，整体文本层级的可读性更佳。

**新引入的问题**:无明显视觉回归，布局尺寸与网格间距均保持像素级一致。

## 03-nosql —— 改前更好

改动前侧栏的「筛选对象」与顶栏的「搜索对象或执行命令」输入框具备清晰适度的边框线条，控件轮廓明确，在浅色背景下具备良好的视觉边界与操作引导。

**新引入的问题**:改动后将顶栏及侧栏两处搜索输入框的边框过度淡化（近乎融入背景），导致表单控件边界模糊，削弱了交互层级与视觉可读性。

## 04-workbench-dark —— 改后更好

改动后提升了多处文字对比度与辨识度：左侧栏「筛选对象」和顶部「搜索对象或执行命令」的占位符文字更清晰；中央欢迎区的「快速开始」与「最近打开」标题，以及下方数据库类型标签色彩更鲜明，信息层级和阅读体验优于改动前较沉暗的表现。

**新引入的问题**:无明显新问题，仅微调了占位符文字和中心区标题/标签色彩与对比度，未破坏布局和整体深色调质感。

## 05-spec —— 改后更好

改动后对核心语义色（次要前景、强调色、危险、警告、成功）以及 MongoDB 引擎品牌色进行了精准的色值校准，颜色更鲜明且对比度更规范；同时下方的 token 变量名（如 `--bg-canvas` 等代码标签）渲染与字体排版更加清晰工整。

**新引入的问题**:无明显视觉退化与引入问题。

## 15-connect —— 改后更好

改动针对掩码所示的顶部面包屑「连接」、步骤条中未激活的步骤文字（「1 选择引擎」「3 测试与保存」）以及底部操作区的「下一步」按钮文字进行了微调，文字清晰度与对比度略有提升，信息辨识更清晰。

**新引入的问题**:无明显退化，整体布局、边距与输入控件保持完全一致。
