# 改动前后成对比较

> 用 `node tests/review.mjs --compare` 生成。绝对打分有 ±1 分的抖动,
> 成对比较问的是「哪个更好」,相对判断稳定得多。

## 01-workbench-light —— 改后更好

差异掩码显示主要改动集中在主工作区的“快速开始”卡片组及“最近打开”列表上。改动前该引导区块明显偏左，导致右侧大面积留白且视觉重心失衡；改动后整体向右平移居中，工作区的信息排布更加对称平衡。

**新引入的问题**:无

## 02-grid —— 改后更好

改动后右侧编辑区标签栏右侧补充了面板最大化/全屏展开控件，且对数据网格内工具栏、表头与数据行的垂直对齐和内边距进行了像素级规整，表格行内文字居中更严谨舒适。

**新引入的问题**:无

## 03-nosql —— 改后更好

改动后集中重构了右侧 Redis 视图的工具栏与键列表区域（掩码显示从 Tab 栏、过滤工具栏至键值表格整体调整）：改动前键名搜索框与 db 连接信息挤在同一行且宽度局促；改动后搜索框独立成行并大幅拉宽，且新增了明确的「筛选」按钮，输入体验更舒展；表格区域行高与垂直对齐随之微调，信息排版更为清晰规整。

**新引入的问题**:无明显新问题，各列数据与底部状态统计均完整展示，未出现遮挡或文字溢出截断。

## 04-workbench-dark —— 改后更好

改动后将右侧主工作区内的「快速开始」卡片组与「最近打开」列表从原本靠左偏置调整为工作区水平居中，让宽屏下的视觉重心更平衡，消除了右侧大面积空旷失衡的问题。

**新引入的问题**:无明显视觉回归或排版问题。
