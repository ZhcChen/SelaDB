# 改动前后成对比较

> 用 `node tests/review.mjs --compare` 生成。绝对打分有 ±1 分的抖动,
> 成对比较问的是「哪个更好」,相对判断稳定得多。

## 01-workbench-light —— 改后更好

改动后为顶栏全局搜索和侧栏筛选框补充了明确的外边框，大幅增强了输入控件的视觉可供性；同时顶栏下方补充了1px水平分割线，使顶栏与内容区的结构层级划分更清晰。

**新引入的问题**:无明显回退。

## 02-grid —— 改后更好

改动后在顶部搜索栏（右上放大图）补充了明确的圆角输入框边框，强化了全局搜索入口的交互边界与结构感；改动前该搜索框无边界，形似悬浮文本。

**新引入的问题**:侧栏顶部的“筛选对象”输入框移除了原有的外边框（左上放大图），弱化了该区域作为可交互输入框的视觉感知。

## 04-workbench-dark —— 改后更好

改动后为顶栏全局搜索与侧边栏“筛选对象”增加了清晰的输入框边框和背景容器，显著提升了交互控件的识别度，同时区域间的分割边界更明确；改动前搜索框仅有占位文字而缺乏容器形态，不易辨识为可输入区域。

**新引入的问题**:无明显视觉退化。
